# Качество русской диктовки в MyASR

На контрольной выборке число ошибок в словах снизилось с 42 до 26 на 906 эталонных словах. В обеих версиях работали один и тот же движок GigaAM v3 e2e RNN-T int8, словарь и декодер. Изменился расчёт признаков, которые приложение подаёт в нейросеть. Исходная версия проекта — `7556f2e`. [ONNX-модель](https://huggingface.co/istupakov/gigaam-v3-onnx)

## Эксперимент

В оригинальной реализации GigaAM спектр обрабатывает библиотека torchaudio. В MyASR границы мел-фильтров округлялись до целых частотных отсчётов, из-за чего модель получала другие значения энергии в частотных полосах. На первом этапе заменили округление расчётом весов треугольников по точным частотам. На втором этапе привели к исходной реализации оставшуюся часть расчёта спектра — периодическое окно Ханна и ограничение энергии перед логарифмированием. Эффект двух операций второго этапа измерялся совместно. [Код GigaAM](https://github.com/salute-developers/GigaAM/blob/main/gigaam/preprocess.py) · [Описание фильтров torchaudio](https://docs.pytorch.org/audio/stable/generated/torchaudio.functional.melscale_fbanks.html)

| Вариант | Выборка | Ошибки / слова | WER | CER |
|---|---|---:|---:|---:|
| Исходный | Подбор | 63 / 908 | 6,94% | 2,84% |
| Точные частоты мел-фильтров | Подбор | 47 / 908 | 5,18% | 1,92% |
| Мел-фильтры, периодическое окно и ограничение энергии | Подбор | 44 / 908 | 4,85% | 1,87% |
| Исходный | Контроль | 42 / 906 | 4,64% | 1,42% |
| Выбранный по результатам подбора | Контроль | 26 / 906 | **2,87%** | **0,91%** |

На контроле 14 фраз дали меньше ошибок в словах, 4 — больше, у 30 число ошибок совпало. Снижение WER составило 1,77 процентного пункта, или 38% относительно исходного значения. Результат относится к читаемой русской речи. Шумные помещения, разговорную речь и конкретный микрофон пользователя отдельно не измеряли.

## Данные и метрики

Использовали 48 записей русского раздела FLEURS dev (526,62 с) для подбора и 48 записей test (566,88 с) для контроля. Записи выбраны по порядку SHA-256 имён файлов, до запуска распознавания. В выборке каждый идентификатор фразы встречается один раз. Использованы оригинальные монофонические WAV 16 кГц и нормализованные эталонные расшифровки. Набор Google FLEURS опубликован по лицензии CC BY 4.0. [Карточка корпуса](https://huggingface.co/datasets/google/fleurs) · [Лицензия](https://creativecommons.org/licenses/by/4.0/)

WER учитывает замены, пропуски и вставки слов, CER — символов. В обоих случаях суммарное число правок по всем записям делится на общее число эталонных единиц. Для обеих сторон используются нижний регистр, Unicode NFC, замена «ё» на «е» и выделение последовательностей букв и цифр. Для CER пробелы убираются. Цифры и их словесное написание оцениваются как разные токены. Пунктуация и регистр в эти показатели не входят.

## Как повторить

Нужны Windows x64, .NET 11 SDK, Python 3.11+ и файлы модели. При первом запуске приложения выберите GigaAM v3 e2e int8 и дождитесь загрузки. Утилита оценки использует те же файлы из каталога моделей приложения или каталога, указанного в `MYASR_MODELS_DIR`.

Выполните из корня проекта в PowerShell. Скрипт подготовки скачивает размеченные записи фиксированной ревизии корпуса и сверяет SHA-256. Каждый JSON-отчёт содержит эталон, результат распознавания, число ошибок и длительность по каждой записи.

```powershell
python tools/prepare_fleurs_ru.py
$env:DOTNET_PROCESSOR_COUNT = '4'
dotnet build tools/AsrEval -c Release
$runner = 'tools/AsrEval/bin/Release/net11.0-windows/AsrEval.dll'
dotnet $runner .asr-eval/fleurs-ru/validation.manifest.tsv .asr-eval/validation.json
dotnet $runner .asr-eval/fleurs-ru/test.manifest.tsv .asr-eval/test.json
```

Для воспроизведения исходного результата распакуйте ревизию `7556f2e` в отдельный каталог, скопируйте туда `tools/AsrEval` из текущей версии и соберите утилиту там. Передайте ей те же манифесты по абсолютным путям. Для промежуточного этапа замените в этой копии только `MyASR/Features/MelFilterBank.cs` текущей версией и повторите прогон на dev. На новых итерациях сравнивайте кандидатов на dev и фиксируйте выбор до проверки на независимых записях.
